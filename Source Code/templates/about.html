About Our System

The Accident Severity Prediction System is designed to analyze real-world accident data and predict whether a road accident is Slight, Serious, or Fatal. This solution helps authorities take preventive measures and enhances road safety using AI.

✨ Key Features

🚗

Accurate Predictions

Uses CNN + BiLSTM + Attention model with DeepSHAP explainability.

📊

Real-Time Processing

Predict accident severity instantly with optimized backend.

🔐

Secure Login

Encrypted account handling with personalized access.

⚙️

Deep Learning Engine

Powerful PyTorch model replicating IEEE research architecture.

🚀 Our Development Journey

📅 Phase 1 – Research & Dataset

Collected and analyzed UK and us traffic accident dataset with preprocessing.

🧠 Phase 2 – Model Engineering

Implemented CNN + BiLSTM + Attention model from base IEEE paper.

📈 Phase 3 – Training & Evaluation

10-Fold Cross Validation, SHAP explainability, performance tuning.

🌐 Phase 4 – Web Deployment

Developed Flask interface with secure login and prediction dashboard.
